# 🔗 Personal Linktree – Free & Customizable

A simple, self-hosted Linktree alternative built using **HTML**, **CSS**, and optionally **JavaScript**. Skip the premium fees and take full control of your personal link hub with this open-source, fully customizable solution.

## 🌐 Live Demo

[👉 View it live here](https://natnael22sds.github.io/link-tree/)

## 🎯 Why Build Your Own?

Many people pay monthly for premium Linktree features like extra links, customization, or analytics. This project gives you complete **freedom and flexibility** with **no cost** — just edit some basic HTML/CSS and you're set.

### 💸 Benefits Over Linktree Premium

- 💰 **Completely free**
- 🎨 Fully customizable (colors, fonts, layout)
- 🔒 No tracking, full privacy
- 🚀 Deployed in seconds via GitHub Pages
- 🧠 Learn by doing – great for beginners in web dev

## 🛠️ Tech Stack

- ✅ HTML5 – Page structure
- ✅ CSS3 – Custom styling
- ✅ JavaScript (Optional) – Interactivity or animations
